# Training data sources

All training data was recorded by our team, playing Street Fighter II Turbo in the supplied
BizHawk emulator with `PythonAPI/record.py`. No external datasets, pretrained models, or other
teams' data or code were used.

| File(s) | Recorded by | Character(s) played | Opponent | Approx. minutes |
|---|---|---|---|---|
| `recordings/rec_..._P1.csv` | _name_ | _e.g. Ryu_ | CPU | _xx_ |
|  |  |  |  |  |

Organizer-supplied data used: _none_ / `normalized_dataset_0.csv` (only if trained with `--include-kit-data`).

Exact file list used for each model: see `data_files` in `models/model_shared.keras.meta.json`.
